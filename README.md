# Data Cleaning & Reporting Automation

Automated Python data engineering and reporting pipeline for retail sales data.

## Features
- Automated duplicate checking, missing value imputation, and text standardisation.
- Chronological and shipping duration feature engineering.
- Automated KPI tracking (Total Orders, Revenue, Profit Margin).
- Generates multi-sheet Excel reports (`Automated_Executive_Report.xlsx`) and summary visualizations (`automated_reporting_summary.png`).
